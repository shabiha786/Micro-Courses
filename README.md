## Practice Dataset

**File:** `Mumbai_emp.csv` (14 rows, 6 columns)

| Column | Description |
|--------|-------------|
| Employee_ID | Unique employee ID |
| Employee_Name | Name of the employee |
| Department | IT, Finance or HR |
| City | City of work |
| Salary | Salary of the employee |
| Joining_Year | Year the employee joined |

The dataset has inconsistent name casing, extra spaces and repeated records, so it is useful for practicing data cleaning in Power Query Editor.
